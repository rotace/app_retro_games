# Contract: Core Perlin Noise Generation Interface

## 概要

`core` クレートは、指定された次元とオフセットに基づいてパーリンノイズ値を計算し、提供されたピクセルバッファに直接書き込むための関数を提供します。このインターフェースは、`runner-debian` クレートのようなプラットフォーム固有のランナーが、描画のためにノイズデータを取得するために使用することを意図しています。

## インターフェース定義

### 関数: `fill_noise_buffer`

```rust
/// 指定されたピクセルバッファにパーリンノイズデータを生成して書き込む。
///
/// `buffer` は、幅 `width` と高さ `height` の画面に相当するピクセルデータへの可変参照。
/// 各ピクセルは `bytes_per_pixel` バイトで構成される。
/// `x_offset`, `y_offset`, `z_offset` はノイズ生成の開始オフセット。
///
/// # 引数
/// - `buffer`: `&mut [u8]` - ピクセルデータが書き込まれるミュータブルなバッファ。
/// - `width`: `u32` - 描画領域の幅（ピクセル単位）。
/// - `height`: `u32` - 描画領域の高さ（ピクセル単位）。
/// - `bytes_per_pixel`: `u32` - 1ピクセルあたりのバイト数。
/// - `x_offset`: `f32` - ノイズ生成のためのX軸オフセット。
/// - `y_offset`: `f32` - ノイズ生成のためのY軸オフセット。
/// - `z_offset`: `f32` - ノイズ生成のためのZ軸オフセット。
/// - `scale`: `f32` - ノイズのスケールファクター。
///
/// # エラー
/// 特になし。この関数は直接エラーを返さないが、
/// 内部的な処理でパニックが発生しないよう設計されている必要がある。
/// (Rustの憲法原則に従い、内部エラーはResultで処理されるべき)
pub fn fill_noise_buffer(
    buffer: &mut [u8],
    width: u32,
    height: u32,
    bytes_per_pixel: u32,
    x_offset: f32,
    y_offset: f32,
    z_offset: f32,
    scale: f32,
) {
    // 実装は core クレート内に含まれる
}
```

## データフォーマット

*   `buffer` は、各ピクセルが `bytes_per_pixel` で指定されたバイト数で表現される生のバイト配列です。
*   ノイズ値（0.0〜1.0）は、ピクセルのグレースケール値（0〜255）に変換されて書き込まれます。例えば、`value * 255.0` の結果を `u8` にキャストして使用します。
*   具体的なピクセルフォーマット（例: RGB888, ARGB8888）は `runner-debian` クレートによって決定され、`core` クレートは提供された `bytes_per_pixel` に従って各ピクセルのカラーチャンネルにノイズ値を適用します。

## 考慮事項

*   `core` クレートは、指定されたバッファサイズが `width * height * bytes_per_pixel` と一致することを前提とします。バッファオーバーフローを防ぐため、呼び出し元は適切なサイズのバッファを提供する必要があります。
*   パフォーマンスを考慮し、ノイズ生成とバッファ書き込みは効率的に行われるべきです。
