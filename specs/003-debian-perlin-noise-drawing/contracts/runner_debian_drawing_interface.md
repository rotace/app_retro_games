# Contract: Runner-Debian Drawing Interface

## 概要

`runner-debian` クレートは、Debian環境のFramebufferにパーリンノイズパターンを描画するためのコマンドラインインターフェース（CLI）を提供します。このインターフェースは、開発者が描画機能の健全性を検証するためのシンプルなエントリポイントとして機能します。

## インターフェース定義

### コマンド: `draw-noise`

このコマンドは、指定されたパラメータに基づいてパーリンノイズパターンを生成し、Framebufferに描画します。

```bash
cargo run --bin runner-debian draw-noise [OPTIONS]
```

### オプション

*   `--width <WIDTH>`:
    *   **説明**: 描画する画面の幅（ピクセル単位）。
    *   **型**: `u32`
    *   **デフォルト**: Framebufferの自動検出された幅
    *   **必須**: いいえ
*   `--height <HEIGHT>`:
    *   **説明**: 描画する画面の高さ（ピクセル単位）。
    *   **型**: `u32`
    *   **デフォルト**: Framebufferの自動検出された高さ
    *   **必須**: いいえ
*   `--x-offset <OFFSET>`:
    *   **説明**: ノイズ生成のためのX軸オフセット。
    *   **型**: `f32`
    *   **デフォルト**: `0.0`
    *   **必須**: いいえ
*   `--y-offset <OFFSET>`:
    *   **説明**: ノイズ生成のためのY軸オフセット。
    *   **型**: `f32`
    *   **デフォルト**: `0.0`
    *   **必須**: いいえ
*   `--z-offset <OFFSET>`:
    *   **説明**: ノイズ生成のためのZ軸オフセット。
    *   **型**: `f32`
    *   **デフォルト**: `0.0` (3Dノイズの静的なスライス用)
    *   **必須**: いいえ
*   `--scale <SCALE>`:
    *   **説明**: ノイズのスケールファクター。値を大きくするとノイズの「粒度」が細かくなります。
    *   **型**: `f32`
    *   **デフォルト**: `0.01`
    *   **必須**: いいえ
*   `--framebuffer <PATH>`:
    *   **説明**: 使用するFramebufferデバイスのパス。
    *   **型**: `String`
    *   **デフォルト**: `/dev/fb0`
    *   **必須**: いいえ

## 成功時の出力

描画が成功した場合、CLIは成功メッセージを出力し、Framebufferにノイズパターンが表示されます。

```text
Perlin noise drawn successfully to framebuffer! Press Enter to exit.
```

ユーザーがEnterキーを押すまで、描画された状態を維持します。

## エラー時の出力

エラーが発生した場合（例: Framebufferデバイスが見つからない、権限がない、不正な引数など）、CLIはエラーメッセージを出力し、非ゼロの終了コードで終了します。

```text
Error: Failed to open framebuffer device: Permission denied
```

## 考慮事項

*   Framebufferのパラメータ（幅、高さ、ピクセルフォーマットなど）は、デフォルトでシステムから自動検出されます。明示的に指定された場合はそれが優先されます。
*   描画にはFramebufferへの書き込み権限が必要です。通常はroot権限または適切なグループに属している必要があります。
